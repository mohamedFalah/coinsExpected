Live Scrape / Sync from EasySBC.io

Pulls live ratings, prices and attributes directly from EasySBC's own player API (found via their site's network requests) and syncs them into the database below. The full EasySBC database has 1000+ pages (~20k players) sorted by meta rating, so pick how many pages to pull — each page is about 20 players.

1. Open the EasySBC players page in your browser.

2. Open DevTools (F12) → Network tab → filter by "Fetch/XHR".

3. Reload the page and look for a request returning JSON player data.

4. Copy that request's URL (without the page number) and paste it into the field below, then click "Scrape & Sync Now".
